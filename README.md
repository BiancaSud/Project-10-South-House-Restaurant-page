## About

South House is a restaurant chain page covering opening hours, menu categories and locations. Compared with my earlier projects it is deliberately restrained — fewer sections, more attention to type and spacing.

This is the first project where I chose typefaces intentionally rather than accepting browser defaults, pairing a script face for display headings with a handwritten face for accents.

## Features

- **Navigation** covering home, about, menu, online ordering and catering
- **Opening hours** split by weekday and weekend
- **Menu overview** across seven categories — starters, breakfast, main courses, fast food, salads, desserts and cocktails
- **Five locations** across southwestern Ohio, each with a full address
- **Contact footer** with per-location phone numbers, careers, delivery and accessibility links

## Built with

HTML5, CSS3, Google Fonts (Dancing Script, Edu VIC WA NT Hand), Font Awesome and Bootstrap Icons via CDN.

## Running locally

```bash
git clone https://github.com/BiancaSud/Project-10-South-House-Restaurant-page.git
cd Project-10-South-House-Restaurant-page
```

Open `index.html` in a browser.

## What I focused on

Typography and restraint. My earlier projects tended to fill every section with as much content as possible; here the goal was the opposite — let the type and the spacing carry the page. Loading fonts from Google Fonts with `preconnect`, and pairing two display faces without them competing, was the main thing I set out to practice.
